## Project Description

RP-Cloud Labs is a proposed platform that allows Rwanda Polytechnic students and lecturers to access hosted learning tools through a web browser without installing the software on their personal computers.

The Tool-Session Service receives student requests to access learning tools and checks whether their college has available software license capacity.

## Objectives

- Allow students to request hosted learning tools.
- Check college license capacity before allocating sessions.
- Track active tool sessions.
- Use Redis for caching session information.
- Use Kafka to publish session-request events.
- Use Flyway to manage database migrations.
- Use Docker to package the service.
- Use GitHub Actions to automate building and testing.
- Deploy and maintain the service using Kubernetes.

## Technologies

- GitHub and GitHub Actions
- Docker
- Kubernetes
- Redis
- Apache Kafka
- Flyway
